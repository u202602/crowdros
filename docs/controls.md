# Controls

## Camera Controls

- `C` : Chase mode, camera follows the robot at eye level
- `B` : BEV (bird's-eye view), still following the robot
- `M` : Manual mode, full manual control via mouse and keyboard (scroll to zoom, right-click drag to pan/tilt)
- `[` : move camera up
- `]` : move camera down
- `Arrow keys` : move camera
- `Q` / `E` : rotate camera

## Robot Controls

- `W`, `A`, `S`, `D` : move robot

## Simulation Control

- `R` : reset/restart the simulation
- `Esc` : exit the simulation back to the scene selector
